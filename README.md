# 🎓 CampusCore - Student Management System

> A Python-based Student Management System designed to simplify student record management, attendance tracking, GPA calculation, and academic statistics.

---

## 📌 About The Project

After completing my Python learning journey and understanding core programming concepts, I wanted to build a real-world project instead of only practicing small programs.

The goal was to solve a practical problem: managing student records efficiently through a structured and organized system.

While developing CampusCore, I focused on creating a project that was not just a simple CRUD application, but a complete management system by applying Python concepts in a practical environment.

During the development process, I implemented many Python concepts including file handling, object-oriented programming, data validation, error handling, modular programming, and structured project organization.

---

## 🚀 Features

### 🔐 Authentication
- Secure login system for administrator access.
- Only authorized users can manage student records.

### 👨‍🎓 Student Management
- ➕ Add new students
- 🔍 Search students by roll number or name
- 📋 Display all students
- 🔄 Update student information
- 🗑️ Delete student records with confirmation
- 🚫 Prevent duplicate roll numbers

### 📊 Display & Filtering
- Sort students by:
  - Roll number
  - Name
  - Age
  - Semester

- Filter students by:
  - Semester
  - Course

### 📝 Attendance Management
- Mark daily attendance.
- Prevent duplicate attendance entries on the same date.
- View attendance by specific date.
- Calculate attendance percentage.

### 🎓 GPA & Academic Management
- Calculate GPA.
- Calculate CGPA.
- Grade-based calculation system.

### 📈 Statistics
Generate useful student statistics:
- Total students
- Total courses
- Students per semester
- Average student age
- Duplicate record detection

### 📄 Report Generation
- Generate formatted reports.
- Includes date and time.
- Displays important statistics.

## ▶️ How to Run
```
1. Install Python 3.x on your computer.
2. Clone this repository using Git or download it as a ZIP from GitHub.
3. Open the cloned/downloaded project folder in VS Code.
4. Open the inner `CampusCore` folder.
5. Open a terminal inside the `CampusCore` folder.
6. Run `python main.py` to start the application.
🎯 Purpose
```
